# Task Tracker Mini Project

A command line menu_based task manager. It stores tasks in a json file named as tasks.json. Each time ypu perform any task the file get updated.

## Features

* **ADD task:** You can add task by giving title by default it'll be saved as Pending.
* **View task:** You can view all the tasks availabel in json file.
* **Complete Task:** you can change the status of your tasks. from penidng to done.
* **Delete Task:** Removes tasks by task number given by user

## Files include:

* `mini_tracker.py`
* `tasks.json`
* `README.md`

## How to run

Open your terminal and run the script:

```bash
python mini_tracker.py
```
